# HandsApp Front
Фронтовая часть для проекта HandsApp API (https://github.com/aspmap/HandsApp_API)

**Старт проекта:** 9 мая 2025 г.

:computer: **Требования к софту:**
1. ReactJS

:computer: **Разворачивание и запуск проекта:**
1. Клонируем проект: git clone https://github.com/aspmap/HandsApp_Front
2. Запускаем приложение

:white_check_mark: **Что реализовано:**
1. Авторизация через JWT-токен. Получение постов пользователя с микросервиса HandsApp API (https://github.com/aspmap/HandsApp_API)
